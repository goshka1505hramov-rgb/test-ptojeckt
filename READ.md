# Random Task Generator

**Автор:** Георгий Храмов

## Описание проекта
Random Task Generator — это GUI-приложение, разработанное на языке Python (библиотека `tkinter`). Программа помогает пользователю бороться с прокрастинацией и хаотичным планированием дня. 

**Ключевые возможности:**
- **Генерация задач:** Выбор случайной задачи из предопределенного списка.
- **Фильтрация:** Возможность выбора задач по категориям: «Учёба», «Спорт», «Работа».
- **Интерактивность:** Возможность добавлять собственные задачи в список.
- **Сохранение:** История всех сгенерированных задач сохраняется в локальный файл `history.json`, что позволяет просматривать статистику после перезапуска программы.

## Инструкция по использованию

### Требования
- Python 3.x
- Библиотека `tkinter` (обычно входит в стандартную установку Python)

### Запуск
1. Убедитесь, что у вас установлен Python.
2. В терминале перейдите в папку с проектом:
   `cd Desktop/phytonn`
3. Запустите основной файл:
   `python main.py`

### Примеры использования
1. **Генерация задачи:**
   - Выберите в выпадающем списке категорию «Спорт».
   - Нажмите кнопку **«Сгенерировать задачу»**.
   - В поле результата отобразится случайная задача, например: «Пробежка 3км (Спорт)».

2. **Добавление задачи:**
   - Введите текст «Сходить в магазин» в поле ввода.
   - Выберите тип «Работа» в выпадающем списке.
   - Нажмите **«Добавить в список»**. Теперь эта задача будет участвовать в генерации.

3. **История:**
   - Все сгенерированные задачи автоматически попадают в нижний список «История» и сохраняются в файл `history.json`.
